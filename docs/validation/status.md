## Distribution and next work

The portable release is framework-dependent Windows x64 and requires the .NET 9 Desktop Runtime. It includes project binaries, reviewed fixtures, and docs. User data and vendor installers/drivers are excluded. An installer and independent DSP/driver are future work in the [dependency plan](../roadmap/installer-and-dependencies.md).

Prioritize GSX saved-state/managed lifecycle integration, remaining fresh-session effects, cold-start checks, clean-machine dependency verification, and pickup-status evidence before claiming broader independence. Cold boot and physical managed reconnect are deferred while the user is actively using this PC. Keep unsupported commands disabled and preserve exact starting state during optional hardware checks.
